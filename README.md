# Unexa — Smart, Secure & Seamless UPI Payments 💜

Unexa is a next-generation digital payments application designed to make everyday transactions smarter, simpler, and more convenient. By bringing personal payments and group expense management together in one platform, Unexa aims to deliver a seamless payment experience with a modern interface and intelligent financial tools.

✨ Key Features
- **Personal UPI Payments** — A streamlined experience for everyday payment activities.
- **Group Pools & Smart Splits** — Organize shared expenses, split bills, track contributions, and manage group balances.
- **AI Scam & Phishing Shield** — Help users identify potentially suspicious payment requests and phishing attempts.
- **Quick Payment Tools** — Convenient access to payment requests, QR codes, bank transfers, and balance-related features.
- **UPI Lite Support Concept** — Designed with faster, convenient low-value payment workflows in mind.
- **Rewards & Cashback** — A dedicated concept for managing rewards and cashback experiences.
- **Modern User Interface** — A clean dashboard, smooth animations, responsive layouts, and an intuitive user experience.
- **Supabase-Powered Backend** — Built around Supabase for backend services, authentication, and database management.

🎯 Our Vision
To make digital payments more accessible, intelligent, and user-friendly by combining everyday transactions, group financial management, and security-focused features in one unified platform.

🛠️ Technology Stack
- **Frontend:** Web technologies used in the project
- **Backend & Database:** Supabase
- **Deployment:** Netlify

Unexa is an evolving project focused on exploring the future of digital payments through thoughtful design, practical financial tools, and security-conscious development.
